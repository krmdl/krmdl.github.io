# POLIDIV portfolio

A responsive portfolio for POLIDIV, showcasing Unity environments and modular 3D props.

## Files

- `index.html` — page content and metadata
- `styles.css` — responsive styling and decorative geometric artwork
- `favicon.svg` — site icon

The site uses plain HTML and CSS, with no build step, external fonts, tracking, or third-party libraries. The abstract room graphics are decorative and are not renders of the Abandoned Hospital asset pack.

## GitHub Pages

The intended free address is [https://krmdl.github.io/](https://krmdl.github.io/). To publish from this repository, choose **Settings → Pages → Deploy from a branch**, then select `main` and `/(root)`.
